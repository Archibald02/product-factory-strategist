# Учебное обновление после перерыва

Таблица полностью синтетическая. Это учебный ввод для проверки реакции агента, не показатели МегаФона. Даты — даты двух вымышленных непересекающихся когорт. Единица — допущенный организатор, случайно распределённый между двумя группами. В каждой когорте один организатор учитывается один раз. Активированные — с подтверждённым первым подключением к D7. Support — количество уникальных организаторов с тематическим обращением к D7, а не количество обращений. Скрипт не может проверить уникальность по агрегатам. В реальном тесте нужны проверка дедупликации и независимости, качество назначения и зрелость D7.
