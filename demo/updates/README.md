# Учебное обновление после перерыва

Таблица полностью синтетическая. Это учебный ввод для проверки реакции агента, не показатели МегаФона. Даты — даты двух вымышленных непересекающихся когорт. Единица — допущенный организатор, случайно распределённый между двумя группами. В каждой когорте один организатор учитывается один раз. Активированные — с подтверждённым первым подключением к D7. Support — количество уникальных организаторов с тематическим обращением к D7, а не количество обращений. Скрипт не может проверить уникальность по агрегатам. В реальном тесте нужны проверка дедупликации и независимости, качество назначения и зрелость D7.

## Отчёт до окончания окна

`pilot_early_synthetic.csv` — отдельный учебный снимок по состоянию на конец 9 ноября. Последняя когорта вошла 3 ноября, её D7 доступен к концу 10 ноября при отсутствии задержки выгрузки. Синтетические счётчики последней когорты неполные. Их нельзя смешивать с полностью наблюдаемой когортой.

```sh
python -X utf8 strateg.py analyze demo/updates/pilot_early_synthetic.csv --as-of 2026-11-09
python -X utf8 strateg.py analyze demo/updates/pilot_synthetic.csv --as-of 2026-11-10
```

Первый запуск возвращает `blocked`, по 2 000 организаторов без полного окна в каждой группе и дату новой выгрузки. Эффекты и интервалы не рассчитываются, решение в журнале сохраняется. Второй запуск принимает отдельную дозревшую выгрузку. Изменение одного флага даты на старом файле не делает счётчики полными. При задержке полноты выгрузки используйте `--lag-days`.
