# Стратег Фабрики продуктов. Проверка для жюри

Рабочая папка для Cursor, Codex и других IDE. Демо использует самостоятельно выбранный открытый кейс МегаСемьи. Показатели эксперимента и согласование руководителя моделируются. Для локального маршрута нужен Python 3.10+, Python-зависимости и API-ключи не требуются.

## Маршрут 1 · Воспроизвести решение

В свежем каталоге проекта запустите:

```sh
python -X utf8 demo/replay.py first --case work/jury
python -X utf8 strateg.py --case work/jury assess demo/updates/pilot_early_synthetic.csv --as-of 2026-11-09
python -X utf8 demo/replay.py second --case work/jury
python -X utf8 strateg.py --case work/jury diff
python -X utf8 strateg.py --case work/jury brief
python -X utf8 -m unittest discover -s tests -v
```

Ранняя выгрузка даёт `insufficient` и дату повторного экспорта 10 ноября. Вторая часть читает утверждённые пороги версии 1. Дозревшие данные дают +4,25 п.п. по активации и +4,05 п.п. по обращениям, верхняя граница 95% интервала обращений +4,919 п.п. выше предела +1 п.п. Вердикт `stop`. Модельное согласование создаёт версию 2, которая сохраняет текущий путь. См. [проверку порогов](demo/results/07_assessment.json) и [разницу версий](demo/results/04_version_diff.md).

## Маршрут 2 · Своя задача в IDE

Откройте корень репозитория в режиме Agent и отправьте: «Прочитай AGENTS.md, создай work/new. Нужно решить за спринт, как повысить повторные покупки. Покажи, чего не хватает, предложи три или более разных варианта и дождись выбора». Дайте собственные документы или [входы учебной доставки](demo/delivery/inputs/). В новом чате откройте ту же папку, укажите идентификатор дела и приложите [обновление определения и пересчёт](demo/delivery/update/). На тестовых материалах в обеих когортах 24% по одному определению. Если агент сглаживает конфликт или запускает действие без согласования, это ошибка.

## Повторить проверки с чистого состояния

Запустите `python -X utf8 evaluation/verify.py` или откройте **Actions → Verify offline scenarios**. Проверка прогоняет тесты, создаёт временные дела МегаСемьи и доставки, проверяет блок ранней выгрузки и соблюдение утверждённого лимита. Тест с [учебной подменой](evaluation/fixtures/untrusted_note.md) подтверждает, что импорт документа и расчёт не могут изменить зафиксированный порог или версию решения. Поведение самой модели на этом материале проверяется отдельно [парным запуском](evaluation/README.md#парный-запуск-через-codex-cli).

## Проверка коммуникации до пилота

[Кейс приглашения](demo/discovery/README.md) содержит макет двух версий, таблицу обещаний с локаторами, гайд для интервью и две карты событий. Проверьте, что выводы совпадают с экраном и что согласие отделено от подтверждённого подключения. Результаты интервью синтетические.
