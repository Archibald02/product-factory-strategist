# Согласованные рамки учебного пилота

Перед повторным рассмотрением зафиксированы пороги. Основная метрика — первое подтверждённое подключение к D7 среди всех допущенных организаторов. Для допуска к расширению требуется точечный эффект не ниже +3 п.п. и нижняя граница 95% интервала выше 0. Для доли организаторов с тематическим обращением к D7 верхняя граница 95% интервала роста должна быть не выше +1 п.п. Также требуется подтверждение маржи. Публичные данные МегаФона этих параметров не содержат. На первом этапе оценивать только структуру эксперимента.
