# Устойчивость. Ожидаемое и наблюдаемое поведение

Команда проверки: `python -X utf8 -m unittest discover -s tests -v`. Данные кейсов искусственные.

| Сценарий | Ожидание | Результат теста |
|---|---|---|
| Ранний CSV когорты МегаСемьи | При выгрузке 9 ноября для когорты от 3 ноября указать 10 ноября и сохранить решение | `blocked`. По 2 000 организаторов без полного окна в каждой группе. Эффекты отсутствуют. Снимки журнала до и после совпадают. |
| Дозревшая выгрузка | Измерить эффект, применить согласованный порог обращений | Данные готовы. Активация +4,25 п.п. Обращения +4,05 п.п. выше лимита +1 п.п. После учёта данных принята учебная версия «оставить как есть». |
| Противоречащий материал | Открыть проверку связанного факта, сохранить действующее решение | При зарегистрированном влиянии C001 попадает на пересмотр. Повторное предложение со спорным фактом отклоняется. Согласованная версия 1 сохраняется. |
| Повторное добавление CSV | Вернуть прежний ID | В журнале сквозного теста семь уникальных источников вместо восьми операций импорта. |
| Отзыв источника | Обозначить связанный факт устаревшим, исключить старый источник из поиска | Источник заменён. CLI не позволяет подтвердить старый факт. Поиск возвращает новую строку. |
| Пропал файл затрат, изменилось определение повторного заказа | Зарегистрировать пробел и сравнить когорты по одному событию | Сценарий доставки продолжился после ошибки файла. Сопоставимая доля 24% в обеих когортах. Промокод не инициирован. |
| Передача решения руководителю | Краткая карточка и разница двух версий читаются из того же журнала | Из версии 2 видны основание, возражение и ответственный. Сравнение показывает S007, отозванное основание, закрытое и новое обязательства. |
| Утверждённый порог нарушен при росте активации | Считать пороги из сохранённой версии и вернуть остановку | Активация проходит, обращения не проходят. Маржа остаётся неизвестной. Журнал не меняется. |
| Числа проходят пороги, экономика отсутствует | Запросить данные, а не одобрить расширение | `insufficient`. После передачи положительного сценария — `review`, требуется решение человека. |
