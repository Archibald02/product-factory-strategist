# Методы для пилота с двумя независимыми группами

Все примеры ниже используют учебные допущения. Для принятия решения нужны фактическая скорость набора, базовые доли и подтверждённые затраты.

## Планирование

```sh
python -X utf8 strateg.py plan-pilot --activation-base-pct 20 --activation-lift-pp 3 --support-base-pct 2 --support-expected-pp 0 --support-limit-pp 1 --daily-eligible 400
```

Для активации используется нормальное приближение к мощности двустороннего теста разности независимых долей при уровне 5%. Для обращений считается размер выборки, при котором верхняя граница двустороннего 95% интервала с заданной мощностью оказывается ниже предела. В расчёте обращений размер эффекта равен расстоянию от ожидаемой разности до предела. Берётся большее из двух требований и округляется вверх для каждой группы. Подход и интервал независимых долей описаны в [работе о планировании](https://pubmed.ncbi.nlm.nih.gov/26625475/) и [работе Ньюкомба](https://pubmed.ncbi.nlm.nih.gov/9595617/).

Целевая мощность относится к каждому условию по отдельности. Она не равна совместной вероятности прохождения всех проверок. В частности, если истинный прирост ровно +3 п.п., оценка превысит отдельное требование к точечному приросту +3 п.п. примерно в половине повторов. Для кластеризации, повторных наблюдений, неодинакового набора или досрочных остановок нужно другое планирование. Редкие события требуют отдельной проверки точности приближения. Скорость набора означает суммарный поток по обеим группам.

## Экономика

```sh
python -X utf8 strateg.py economics --activation-delta-pp 4.25 --support-delta-pp 4.05 --eligible 10000 --fixed-cost 120000 --support-cost 180
```

Дополнительная стоимость на допущенного участника равна фиксированным затратам, делённым на охват, плюс разность долей организаторов с обращением, умноженная на стоимость обработки в расчёте на одного такого организатора. При положительном приросте активации отношение этой стоимости к приросту доли даёт требуемый вклад одной дополнительной активации. При неположительном приросте этот показатель не определён. Для примера стоимость равна 19,29 ₽ на допущенного и требуется 453,88 ₽ вклада на дополнительную активацию. Обращения могут происходить несколько раз, поэтому подставляется стоимость обработки на организатора с хотя бы одним обращением, в одинаковом горизонте и валюте.

Опциональный вклад на одну дополнительную активацию должен быть уже за вычетом переменных расходов, не учтённых отдельно. Отрицательная разность по обращениям уменьшает затраты по сценарию. Модель линейная, не учитывает каннибализацию и неопределённость оценок без дополнительных входов.
